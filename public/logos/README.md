Logos shown in the app bar, right of "Liu Lab @ VIB-KU Leuven Center for Neuroscience".

Place them here as:

- `logo1.png`
- `logo2.png`

They are scaled to 32 px high (width follows the aspect ratio). A missing file is
not shown. To use other names or formats (e.g. `.svg`), edit `LOGOS` in `src/App.js`.
With `npm start` they appear on reload; for a production build, run `npm run build` again.
